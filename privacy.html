Privacy Policy - Echo Assistant

Last updated: 24 September 2026

Echo Assistant is a private automation tool used by a single person, its owner. This policy explains how it handles Google account data.

Who uses the application

The application is operated exclusively by its owner on his own devices. It is not distributed to, or used by, any other person.

What data is accessed

With the owner's explicit consent, the application may read and manage the owner's own Gmail messages and labels, Google Calendar events, and Google Drive files, documents, spreadsheets and presentations. Access is limited to the scopes shown on the consent screen.

How data is used

Data is used only to perform tasks the owner requests, such as summarising email, creating calendar events, or organising documents. No data is sold, rented, or shared with third parties. No advertising is involved.

Where data is stored

Data is processed on the owner's own computer. Authentication tokens are stored locally on that computer and are never transmitted anywhere except to Google's own API endpoints.

Retention and deletion

Content retrieved from Google APIs is kept only as long as needed for the requested task. The owner can revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the application's tokens.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
